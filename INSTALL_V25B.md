# V25B — Standalone top-left horn mark

Use over V25A. This **only changes `static/style.css`**; the favicon image and header markup installed by V25A remain unchanged.

1. Extract the ZIP.
2. In GitHub Desktop, use Repository > Show in Explorer.
3. Copy `static/style.css` into the matching `static` folder, replacing the previous file.
4. Commit with summary `V25B - Move header horn above wordmark`, then Push origin.
5. Wait for Cloudflare Pages to deploy.

The horn now sits at the top-left above the site name instead of on the same line. Navigation remains on the right on desktop and beneath the name on mobile. Existing photos, content, notes, uploader, R2, and favicons are unchanged.
