# Nicholas Kincaid Photography — V13

Lightweight static photography portfolio built with Python and served by Cloudflare Pages. Private browser-based editor at `https://nickckincaid.com/admin/` with GitHub OAuth. All code is plain HTML/CSS/JavaScript/Python; no production database or JavaScript build step.

## Deployment

- Repository: `NickcKincaid/photos-1`, branch `main`
- Cloudflare Pages build command: `python3 build.py`
- Output directory: `dist`
- Leave root directory blank.
- Do not commit `dist/` (it is generated by Cloudflare).

### Important paths

- `build.py`: public HTML pages, project galleries, metadata, sitemap and responsive image markup.
- `static/style.css`: minimal Leelawadee UI design (public text ≤12px).
- `static/site.js`: full-screen viewer, touch gestures, shareable photo URLs.
- `static/admin*`: private phone/desktop photo editor and image preparation.
- `functions/`: Cloudflare Pages server functions for authentication and GitHub publishing.
- `admin-lib/`: shared authentication and GitHub API code (no credentials stored here).
- `scripts/`: automated filename normalization, creator credit, GPS scrubbing and image optimization.
- `.github/workflows/rename-project-photos.yml`: metadata processing and WebP generation.
- `content/site.json` and `content/projects/*.json`: your editable site and project data (KEEP).
- `media/`: your photos and generated optimized variants (KEEP).

To publish, sign in to `/admin/`, make changes and save. Changes are committed to GitHub; GitHub Actions processes the photos; Cloudflare Pages publishes the new site. Documentation for configuring the credentials is in `ADMIN_SETUP.md`.
